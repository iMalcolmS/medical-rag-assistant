# 🏥 Medical RAG Assistant

A clinical question-answering system that combines **FHIR R4** patient data 
with **Large Language Models** using Retrieval-Augmented Generation (RAG).

## Stack
- **LlamaIndex** — RAG pipeline
- **Groq + Llama 3.3** — LLM inference
- **HuggingFace Embeddings** — local vector embeddings
- **FHIR R4 (Synthea)** — synthetic clinical data

## Phases
- ✅ Phase 1 — Project setup
- ✅ Phase 2 — FHIR data loader
- ✅ Phase 3 — RAG pipeline
- 🔄 Phase 4 — Streamlit UI (coming soon)

## Usage
```bash
python test_rag.py
```
